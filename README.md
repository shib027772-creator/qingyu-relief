# 轻愈 Qingyu

一个移动端优先的情绪舒缓 H5 原型，面向急性焦虑、惊恐感和长期情绪内耗人群，提供低刺激、低决策成本的情绪自助引导。

在线体验：  
[https://qingyu-relief.vercel.app](https://qingyu-relief.vercel.app)

> 说明：Vercel 在中国大陆访问可能不稳定。若用于简历/作品集长期展示，建议同步部署到国内友好的静态托管平台，见 [部署说明](./docs/DEPLOYMENT.md)。

## 项目背景

很多情绪工具会把用户引向复杂内容、社交、咨询预约或付费服务，但人在急性焦虑状态下真正需要的是更少选择、更清晰的安全提醒，以及可以立刻开始的小动作。

「轻愈」的第一版目标不是替代专业帮助，而是验证一个轻量工具是否能在用户不舒服时提供温柔、克制、可操作的自助入口。

## 产品定位

- 不做社交
- 不做 AI 聊天
- 不做心理咨询
- 不做付费会员
- 不做医疗诊断或治疗建议
- 核心急救功能尽量断网可用
- 心情记录优先本地保存，降低敏感数据上传压力

## 核心功能

### 需要帮助

用于用户正在经历急性焦虑、惊恐感、呼吸急促、心慌或难以回到当下时。

- 紧急求助说明
- 呼吸困难安全提示
- 478 呼吸法
- 方块呼吸法
- 54321 接地法
- 降温法 / 冷水刺激安全指引

安全边界：

- 不建议塑料袋/纸袋呼吸
- 不做呼吸性碱中毒诊断
- 出现胸痛、持续呼吸困难、晕厥、意识模糊、嘴唇发紫等情况时，明确提示立即拨打 120 或联系现实帮助

### 日常舒缓

用于非急性焦虑状态下的日常自我照顾。

- 正念打卡
- 冥想练习
- 运动打卡
- 渐进式肌肉放松
- 今日书签瓶
- 安心科普

冥想音频第一版接入公开普通话引导音频，页面内保留来源与许可说明。正式上线或商业化前，建议替换为自有授权音频。

### 心情记录

用于记录每日情绪状态，并通过日历和本周小结观察情绪变化。

- 今日心情等级
- 情绪标签多选
- 300 字以内简短备注
- 心情日历
- 本周小结
- 保存 / 修改 / 删除本地记录

## AIGC / Vibe Coding 过程

这个项目通过多轮 AI 协作完成。我的重点不是让 AI 一次性生成页面，而是持续把问题、限制和反馈说清楚：

1. 先定义产品边界：不做社交、不做咨询、不做付费，聚焦情绪自助。
2. 将真实焦虑场景翻译成功能结构：急救入口、日常舒缓、心情记录。
3. 用视觉参考和截图反馈反复调整：字体、留白、色彩、低刺激动效、小愈形象。
4. 对关键交互继续追问：呼吸动画是否连续、暂停重置是否可用、方块呼吸是否平滑移动。
5. 补齐上线意识：本地数据、音频授权、部署方式、国内访问、隐私与安全边界。

## 数据存储

第一版不接入登录和云数据库，核心数据保存在浏览器本地：

- `qingyu_daily_bookmark`
- `qingyu_bookmark_favorites`
- `qingyu_bookmark_history`
- `qingyu_mindfulness_checkins`
- `qingyu_exercise_checkins`
- `qingyu_mood_records`

这种设计适合 MVP 和作品集展示：打开即用、隐私风险低、无需账号授权。后续如需跨设备同步，可以增加“可选登录 + 云端同步”，但急救功能不应被登录流程阻断。
